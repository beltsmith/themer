# Capacity ladder search (H8)

Generated by `harness/ladder.py`. Drop order = which hue family is merged/dropped first as capacity falls; roles of a dropped family follow its YAML `fallback` (quiet roles: `quiet_fallback`, else default). Cost at a level = Σ adjacency × w over the set's must-differ pairs left with no distinguishing channel (static channel model, see static_checks.md) **+ λ · beacon loss** (Σ_roles beacon · ink · loss; loss 1 = falls to plain default, 0.5 = keeps bold or a dim/quiet/faded tier). λ_disc = 0.00134, λ_raw = 0.6139: dropping every hue family of draft-2 landmark costs as much in beacon loss as in pair confusion. **disc.** = pair term × (1 − lexical separability), the version H8 is judged on. YAML order = ascending `keep` (draft 2) / `ladder` (draft 1). Palette-independent: kept families are assumed to get categorically distinct accents.
Adjacency: out/adjacency.csv (adjacent_skip_punct).

## Caveats

- `oddball` (comment.todo) has zero measured ink and adjacency (no injections in the corpus), so confusion cost never penalises dropping it; its value is beacon value, which C6 does not count. Optimal orders that drop oddball first reflect this.
- Static channel model: lightness counts only for designed differences (faded, lightness variant, popout); default vs salient Lc targets are not counted. With a real palette some "hue-only" pairs also differ in lightness.
- Ties in `ladder` ranks (hybrid_v1) are broken by YAML order.
- Families whose fallback keeps a non-hue channel (definition → bold, prose → faded + italic) cost ~0 in pair confusion to drop; the beacon-loss term now charges 0.5 · beacon · ink for them. Whether that is enough to keep them depends on λ (sensitivity table).
