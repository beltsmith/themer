# Static pattern checks (C4, C9, hue budget, coverage)

Generated by `harness/static_checks.py`. Palette-independent. Sets are resolved with `inherits`.
Channel model (see `mapper_common.channels_between`): *hue* = different family (null family = default ink);
draft 1 sets: *lightness* only where the pattern designs it (faded tier, `variant: lightness`, popout Lc 60);
*chroma* = `variant: chroma-low` within a family; default (Lc ≥ 60) vs salient (Lc ≥ 45) is not a lightness channel.
Draft 2 sets (landmark, hybrid): *lightness* = faded / dim vs the rest; *chroma* = none / quiet / loud class
(quiet and dim are D1-distinct at the reliable level by construction in the mapper, or the quiet colour fails and is recorded). *weight* = bold (tier strong/popout); *slant*; *strike*.
Losing hue (H11 ablation) also removes chroma.

Must-differ pairs = role pairs in different families (null family counts as its own group) with w > 0,
plus explicitly weighted pairs inside one family. w = `weights.yaml` pair weight or `default_pair`.
Adjacency source: out/adjacency.csv (adjacent_skip_punct). Separability: 2·balanced_accuracy − 1 from out/recoverability_pairs.csv (ALL) where listed, else 1 − (conf(a→b)+conf(b→a))/2 from out/recoverability_confusion.csv.

## Spec notes found by these checks

- Draft 1 (`*_v1`, label): `ladder` comment says "higher = merged/dropped first", but the numbers only match 00-framework §4 (meta → exit → prose → definition) if *lower* is dropped first. Harness uses lower-first. `oddball` has no fallback and `distinct_from_all` makes it a 6th hue in landmark_v1. Tier `lc` targets put `salient` (45) below `default` (60).
- Draft 2 (landmark, hybrid): `keep` = higher kept longer (same numeric direction as the harness ladder). Four loud hue families; oddball is not a hue family. `lightness+chroma` is one declared axis (salience), so quiet/dim/faded tiers are not monosemy violations; `weight` = landmark (binding sites and oddballs), so bold on popout is declared.
- Draft 2.1: when `value` is dropped, `string` follows `quiet_fallback: {tier: quiet, family: any_kept, else: default}`: it borrows the quiet tint of a kept family (static model: chroma class quiet, no hue channel), else default; never dim, so string/comment keeps lightness and chroma channels. In the static model a borrowed tint is assumed to exist whenever any family is kept.
- Draft 2.1 hybrid: `definition` now declares `quiet_fallback: {tier: default}`, so its quiet use sites (calls, types) go to default, not bold.
