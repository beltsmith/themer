## keyword.exit: refined vs raw selectors

roles.yaml maps @keyword.exception and @keyword.coroutine to keyword.exit, but nvim paints try/catch/except/finally/else, async, Java `throws`, Rust `assert!`/`assert_eq!`/`panic!` macro names (and their `!`) and Lua's `coroutine` table with those captures. role_tokens.py keeps keyword.exit for exit words only (return, raise, throw, yield, await, break, continue, goto, from any keyword capture) and re-homes the rest (try/catch/... -> keyword.flow, async/throws -> keyword.decl, Rust assert macros -> macro.call, Lua coroutine -> module, others -> keyword.other). `goto` is included per the framework's exit family (C/Go only).

## Caveats

- Roles reflect what nvim-treesitter's queries paint. Python docstrings (@string.documentation) are `string` under roles.yaml, so Python's string share (34%) is largely docstrings. Bash `constant` is nvim's ALL_CAPS-variable heuristic (FOO in `$FOO`), so bash constant.* (~16%) is not about declared constants. Rust/C/Lua/Python/Java paint any ALL_CAPS identifier @constant, so constant.use mixes declared constants and convention.
- No injections: comment.todo never fires (TODO markers live in the comment injection), and doc-comment markup stays comment/comment.doc.
- locals.scm is incomplete: e.g. Rust `static` items, Java enum constants and some patterns are missed (partly recovered by the name-field heuristic), Lua global assignments are not definitions, Python re-assignments are (Python binding semantics). Function definitions come from highlights.scm (@function/@function.method). type.def = @type.definition plus @type tokens that locals.scm marks as definitions (most queries paint `class Foo`/`struct Foo` names as plain @type); Lua, bash and elisp have no type captures.
- Import-bound names (@local.definition.import) are not counted as binding sites.
- ALL rows average over 9 languages including zeros where a concept does not exist (no readonly locals in Python/Go/Lua in practice; no declared constants in Python).
- Comment/string shares vary +/-10pp between codebases; token shares and per-screen counts are more stable.
